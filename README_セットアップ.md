# 3院売上集計ダッシュボード — スタンドアロン版（Node.js）

GAS不要。自分のPCで動く単体ツールです。`start.bat` をダブルクリック → ブラウザで表示。
集計コア（売上=契約+単発genuine／消化除外／件数=同会計×同カテゴリ=1件／1日ずつ取得）は
**検証済みのまま**移植しています。

## ファイル
- `server.js` … 本体。APIから取得→集計→ローカルサーバでダッシュボード配信（依存パッケージなし）。
- `index.html` … 画面（サイドバー＋カード4枚＋Chart.js棒+折れ線＋ランキング＋未分類振り分け）。
- `.env.example` … API情報のテンプレート。
- `start.bat` … 起動用（ダブルクリック）。
- `data/` … 自動生成。`master.json`(施術マスタ) と `cache/`(月次キャッシュ)。
- ※ `Code.gs` は旧GAS版の残骸。**このツールでは使いません**（消してOK）。

## 準備（初回だけ）
1. **Node.js をインストール** … https://nodejs.org/ja から「LTS」を入れる（18以上）。
2. **API情報を記入** … `.env.example` を `.env` という名前でコピーし、メモ帳で開いて
   3院の `client_id / client_secret / clinic_id` を記入。
   （`start.bat` を初回起動すると自動で `.env` を作ってメモ帳で開きます）

## 使い方
1. `start.bat` をダブルクリック → 自動でブラウザが開く（手動なら http://localhost:7700 ）。
2. 上部の年/月を選ぶ → 選択月を**ライブ取得**して集計（1日ずつなので数十秒）。
3. 左で院切替・カテゴリ絞り込み。
4. **「未分類を振り分け」** → optionIdごとに候補カテゴリ・候補種別が自動サジェスト。
   確認・修正して「マスタへ保存」→ 即再集計。新規カテゴリ名も入力可。
5. 月別グラフの過去月は、その月を一度表示すると `data/cache` に貯まり、推移が伸びます。
6. 停止は、黒いウィンドウで `Ctrl + C`、またはウィンドウを閉じる。

## 注意
- `.env`（特に client_secret）は**他人に渡さない・ネットに上げない**。
- `data/master.json` が振り分け結果。バックアップしておくと安心。

## 第1版で割り切った点（要相談）
- ランキングは **売上(粗利) / 件数** の2軸。資料の「原価率TOP」は**原価データが未提供**のため未実装
  （マスタに原価列を足せば対応可）。
- 「前回実施」カードは定義未確定のため、代わりに**平均単価**を表示。
- 自動サジェストのキーワードは `server.js` の `CATEGORY_KW`/`MEDIA_KW`/`CP_KW` に最小限。実データに合わせ追記推奨。
